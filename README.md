# 目的
純Rustかつ外部クレートを用いてシェルを自作する。

# 背景
シェルをカスタマイズするためにDSLを勉強するのが面倒。
かといって、シェルをカスタマイズなしで使用するのも面倒。
カスタマイズの必要がなく、便利なシェルが欲しい。
ただし、環境変数、alias、abbrは例外とする。

# 使い方

```sh
cargo run --release
```

`Ctrl+D`（空行）または `exit` で終了する。

貼り付けはブラケットペーストで 1 つのブロックとして受け取るため、複数行を貼っても
途中の改行で即実行されない。2 行以上のときは
`Paste 5 lines starting with "..."? [Enter: paste / Esc: cancel]` と確認し、
`Enter` で 1 行目を入力欄へ、残りを貼り付けキューへ積む（`Esc`/`Ctrl+C` で破棄）。
入力行を実行すると残りが 1 行ずつ順に実行され、各行は履歴にも個別に残る。
ビルトインを含む行も正しく動き、`Ctrl+C` で残りを中断できる。

外部コマンドは先頭トークンの abbr/alias を展開したうえで、行をそのまま
`sh -c` に渡す。パイプ・リダイレクト・グロブ・`$VAR`・クォートはすべて
`sh` が解釈するため、`ls *.rs | grep main > out.txt` のような行も動作する。

# キーバインド

> 各機能の挙動・理由・例まで含む詳細版は [操作マニュアル（MANUAL.md）](MANUAL.md) を参照。

## カーソル移動
| キー | 動作 |
| --- | --- |
| `Ctrl+A` / `Home` | 行頭へ |
| `Ctrl+E` / `End` | 行末へ |
| `Ctrl+B` / `←` | 1 文字左へ |
| `Ctrl+F` / `→` | 1 文字右へ（行末ならゴースト補完を受け入れる） |
| `Ctrl+←` / `Ctrl+→` | 単語または `/` 単位で移動 |

## 編集
| キー | 動作 |
| --- | --- |
| `Backspace` / `Ctrl+H` | カーソル直前を削除 |
| `Delete` / `Ctrl+D` | カーソル位置を削除（空行での `Ctrl+D` は終了） |
| `Ctrl+W` | 単語または `/` 単位で直前を削除 |
| `Ctrl+U` | カーソルより前をすべて削除 |
| `Ctrl+K` | カーソル以降をすべて削除 |
| `Ctrl+L` | 画面をクリアして再描画 |
| `Alt+.` | 直前コマンドの最終引数を挿入 |
| `Ctrl+C` | 入力を破棄 |
| `Ctrl+Z`（外部コマンド実行中） | 実行中のジョブを停止して `fg`/`bg` で再開可能にする |

## 補完・履歴
| キー | 動作 |
| --- | --- |
| `Tab` | 補完（コマンド名 / パス / 環境変数 / `fg`・`bg` のジョブ）。prefix 一致を優先。複数候補はグリッドメニュー |
| `↑` | 履歴を 1 つ前へ |
| `Ctrl+N` / `↓` | 履歴を 1 つ後へ |
| `Ctrl+P` | `cd` で移動してきたディレクトリスタックから選択して挿入（入力が空なら `cd <PATH>`） |
| `Ctrl+R` | 全履歴をインクリメンタル検索 |
| `Ctrl+T` | カレント以下のファイルを検索して挿入（2 段階探索: 浅い階層優先。入力が空なら `cd` モード） |
| `Ctrl+G` | 自動記録したパス（MRU 順）から選択して挿入（入力が空なら `cd <PATH>` を補完） |
| `→`（行末） | ゴースト補完（履歴ベースのインライン候補）を受け入れる |

ピッカー（`Ctrl+R`/`Ctrl+T`/`Ctrl+G`/`Ctrl+P`）の絞り込みはクエリを空白区切りのワード列として扱い、
各ワードを「連続部分一致・左→右の順序」で探す（大小無視）。例: `AAA CCC` は
`/work/AAAAA/BBBB/CCCC` に一致するが `CCC AAA` には一致しない。短いパスほど上位、
末尾（basename）にかかるマッチを加点し、同点は MRU（直近）順で並べる。

開いているピッカーの種別（`history`/`files`/`recent`/`dirstack`）はクエリ行の右端に
`件数` と並べて表示される。ピッカーを開いたまま `Ctrl+R`/`Ctrl+T`/`Ctrl+G`/`Ctrl+P` を押すと
クエリを引き継いでその種別へ切り替わり、同じキーをもう一度押すと閉じる。
`Ctrl+P` が切り替えに使われるため、ピッカー内の「上へ移動」は `↑` / `Ctrl+K`。

# ビルトインコマンド

| コマンド | 説明 |
| --- | --- |
| `cd [DIR]` | ディレクトリ移動。引数なしで `$HOME`、`cd -` で `$OLDPWD`。ファイルを渡すとその親へ移動。移動元はスタックに積み、`Ctrl+P` で選んで戻れる |
| `abbr FROM TO` | 略語を定義（Space／実行時に展開、fish 風の視覚展開） |
| `alias FROM TO` | エイリアスを定義（実行時に先頭トークンを展開） |
| `set VAR VAL` / `setenv VAR VAL` | 環境変数を設定 |
| `source-env FILE [SHELL]` | 別シェルで設定ファイルを source し、その環境変数を取り込む（シェルは拡張子・shebang から自動判別、明示も可） |
| `jobs` | 停止/バックグラウンドのジョブ一覧を表示 |
| `fg [ID/タグ]` / `bg [ID/タグ]` | ジョブを再開。ジョブが 1 つなら即確定、タグ指定で 1 件に絞れれば即確定、それ以外はピッカー |
| `refresh` | `~/.my_shell_paths` を掃除（実在しないパス・重複を除いて compact） |
| `exit [STATUS]` | シェルを終了（引数なしは直前コマンドの終了ステータスを引き継ぐ） |

abbr と alias の違い: `abbr` は入力した略語を Space や実行時にその場で展開して
見せる。`alias` は表示は変えず、実行時に先頭トークンだけ置き換える。

# 設定ファイル

| ファイル | 役割 |
| --- | --- |
| `~/.my_shell_rc` | 起動時に 1 行ずつ実行する設定ファイル（`#` 始まりはコメント） |
| `~/.my_shell_history` | コマンド履歴（タブ区切り `時刻\tcwd\tコマンド`、最大 10,000 件） |
| `~/.my_shell_paths` | コマンド引数から自動記録したパス一覧（MRU 順、`Ctrl+G` で参照） |

`~/.my_shell_rc` の例は [`example/.my_shell_rc`](example/.my_shell_rc) を参照。

# 展開

- `~` / `~/...`: ホームディレクトリ（ビルトイン引数で展開）
- `$VAR` / `${VAR}` / `$$` / `$?`: 環境変数・PID・直前の終了ステータス
  （外部コマンドでは `sh` 側が、ビルトイン引数では本体が展開する）
- `..` / `...` / `....` ...: ドット列をディレクトリ遡上パスに展開（`..` → `..`、`...` → `../..`、以降同様）
  - コマンド位置（行全体がドット列）→ `cd ../..` などに変換。
  - 引数位置（例: `ls ....`）→ 各トークンを展開した上でそのまま渡す。
